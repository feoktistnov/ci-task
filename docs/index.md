# Калькулятор

Простой калькулятор на Python. Текущая версия: 1.0.0.

## Возможности

- Сложение — `add(a, b)`
- Вычитание — `subtract(a, b)`
- Умножение — `multiply(a, b)`

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest
```
